# Island homepage — implemented

The customer homepage uses a real Three.js r169 WebGL2 renderer. The existing business conversation and marketer studio are retained. The scene is independent of the LLM and needs no API key or external asset server.

## Run

Node.js 22 or newer:

```sh
npm install
npm run dev
```

`npm run build` writes the client, shader modules and pinned Three.js runtime to `dist/`. Vercel uses the existing `vercel.json`. No CDN or inline script is needed by the hosted app; the original strict Content Security Policy is unchanged. Run `node scripts/standalone.mjs` to produce a self-contained offline HTML preview. The preview deliberately uses the labeled demo conversation and browser-local storage.

## Scene

- Procedural irregular sea cliff with an elevated grass plateau.
- Animated ocean normals, Fresnel reflection, sunlight and shoreline foam.
- Custom sky/cloud shader and warm directional lights, shadow maps.
- Procedural cottage: gable, overlapping curved shingles, plank walls, porch, recessed windows, chimney and logs.
- Eight branching trees with 23,760 individually instanced leaves on desktop.
- 128,000 curved grass blades on desktop; 44,000 on small viewports. Wind-deformed geometry, flowers and flight animation.
- A faceted explorer with hat, clothing, backpack, walking/idle/jump animation.
- A twelve-second camera orbit and approach; skip immediately or focus the composer to start chatting without waiting.
- Real depth-buffer-based bokeh/DOF and restrained highlight diffusion. This is not a background video or CSS perspective trick.

## Controls

`둘러보기`: Arrow keys / WASD move; Shift runs; Space jumps; drag the scene to turn the camera. Escape or `대화로 돌아가기` returns to the homepage. Character walking has terrain and cottage boundaries; this is a small scene, not a complete game. Mobile supports the scene and touch camera dragging; keyboard walking requires a keyboard.

`다시 보기`: replay the cinematic. `정지 / 재생`: pause motion. Reduced-motion preferences skip the intro and initially pause the scene. The scene is not rendered while the tab is hidden or a non-customer route is active. A WebGL error leaves the regular conversation available, with an explicit notice.

## Source ownership and fidelity

All scene meshes and textures are generated by the source code in `public/world/`. No original paodao.fr models, textures, shaders, audio, font files or recorded frames are shipped. The supplied reference video informed composition and camera movement; the result is an independently built scene, not a pixel-identical copy or a reproduction of the reference's full game. Three.js is MIT-licensed; `scripts/vendor.mjs` copies its license alongside the runtime.

## Files

`math.js`: deterministic layout, terrain and camera points. `craft.js`: mesh batching, procedural materials and wind. `land.js`: cliff and meadow. `objects.js`: cottage, vegetation, traveler and markers. `atmosphere.js`: sky and water. `lens.js`: color/depth postprocessing. `island.js`: lifecycle, camera and controls. `world-controller.js`: lazy route integration. `world.css`: minimal customer overlay only.

## Verification

`npm test`: domain, HTTP API, UI-copy guards and scene invariants. `npm run build`: syntax checks and local runtime packaging. `tests/browser.mjs`: genuine HTTP/Chromium verification of WebGL, camera, character, chat, strategy, request/review/approval, reload persistence and mobile layout. The GitHub workflow installs its pinned Playwright test dependency and runs this check; inspect the actual workflow result before claiming CI passes.

Local creation-environment checks use headful Chromium with SwiftShader. Because that environment prohibits browser navigation, the self-contained HTML is loaded with `set_content` and memory-storage adapters there; the Three.js renderer, shaders and application logic are real. Software rendering is not representative of hardware-GPU frame rates. No cross-device FPS guarantee is made.

## Product boundaries

The existing example mode, browser-local role switching, credential-gated LLM adapter and approval states are unchanged. This work does not add authentication, shared server storage, paid marketer matching, lead collection, external publishing or message sending. No marketing results are fabricated.
